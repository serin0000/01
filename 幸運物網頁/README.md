## 📖 專案簡介

**Lucky Crow（幸運烏鴉）** 是一個結合「暗黑奇幻（Dark Fantasy）」與「神秘占卜」的單頁式互動體驗網站。  
在深邃夜色與鮮明血月（Blood Moon）的映襯下，使用者將跟隨神秘黑烏鴉的指引，抽取今日專屬的命運幸運物，並深入探索不同古老文化中流傳的幸運物傳說與象徵。

---

## 📁 專案檔案結構與儲存說明

本專案採用清晰、純淨且無外部套件依賴（Dependency-Free）的前端工程架構儲存，完整檔案結構如下：

```text
513170500_陳悅琳/
│
├── index.html              # 網頁主架構（包含 Hero 主視覺、今日幸運占卜區、幸運物誌、關於）
├── style.css               # 樣式表（神秘黑夜 × 緋紅血月 × 秘銀調色盤、動畫與 RWD 響應式排版）
├── script.js               # 動態互動腳本（Web Audio API 音效、烏鴉黑羽噴散、3D 傾角與抽籤邏輯）
├── README.md               # 本專案說明文件（包含 513170500_陳悅琳 作者資訊與專案儲存維護指南）
│
└── assets/                 # 靜態資源資料夾
    └── crow-realistic.png  # 寫實神秘黑色烏鴉核心主視覺圖檔
```

### 檔案職責與儲存規範

1. **`index.html`**：
   - 採用語意化 HTML5 標籤（`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`）。
   - 引入 Google Fonts（`Cinzel` 古典英文與 `思源宋體`），強化神秘古典美感。
   - 結構依序規劃：固定式頂部導覽列（含音效開關）、Hero 血月與寫實烏鴉主視覺、今日幸運物卡片翻轉區、四格幸運物誌古老傳說展示、頁尾關於區塊。

2. **`style.css`**：
   - 儲存 **「神秘黑夜 × 紅 × 銀」** 核心色彩變數（CSS Custom Properties）。
   - 內建 `@keyframes` 自訂動畫：呼吸血月（`moonPulse`）、星光閃爍（`starTwinkle`）、烏鴉待機浮動（`crowIdle`）、撲翅躍動（`crowAttack`）、羽毛飛散（`featherFly`）、卡片翻轉（`cardReveal`）等。
   - 內建完整的行動端手持裝置（Mobile & Tablet）響應式媒體查詢（`@media (max-width: 900px)`、`@media (max-width: 768px)`、`@media (max-width: 600px)`）。

3. **`script.js`**：
   - 原生 JavaScript 模組化撰寫，完全不依賴 jQuery、React 或任何外部 CDN。
   - 內建 Web Audio API 音訊振盪合成器（水晶鐘聲、振翅掠風聲、按鈕點擊聲），避免因本機檔案路徑限制導致音效失效。
   - 整合自訂物理羽毛擴散粒子系統與 3D 陀螺儀傾角演算法。

4. **`assets/crow.jpg`**：
   - 儲存於 `assets/` 專用靜態目錄下，作為 Hero 區塊的寫實黑烏鴉核心主視覺圖檔。

## ✨ 完整動態與互動效果規劃

本專案經細緻規劃，涵蓋多元的滑鼠懸停（Hover）、點擊（Click）與視差音效互動：

### 1. 滑鼠懸停互動 (Hover Effects)
- **頂部導覽列**：懸停時文字亮起緋紅光暈，底部紅色底線由中心向兩側展開。
- **Hero 3D 視差微動 (Parallax)**：滑鼠在主視覺區移動時，血月、背景星辰與黑烏鴉會依深度產生不同比例的空間位移。
- **寫實烏鴉**：滑鼠懸停於烏鴉上方時，烏鴉對比度加深、微幅上浮，背後的深紅光暈向外擴散。
- **今日幸運物卡片 3D 陀螺儀懸停**：游標移入卡片時，卡片即時計算游標相對於卡片中心的座標差，產生平滑的 3D 空間傾斜（`rotateX` / `rotateY`），並投射動態聚光燈（Spotlight）。
- **幸運物誌卡片**：每張歷史卡片擁有動態聚光燈層，隨游標位置即時追蹤光斑，並微幅上浮 8px。
- **滑鼠微光星塵軌跡 (Stardust Trail)**：滑鼠滑動於夜空中時，自動在軌跡後方落下漸隱淡出的微型紅銀星光。

### 2. 點擊動畫與即時回饋 (Click Animations)
- **全域點擊水波光環 (Click Ripple)**：點擊畫面任意位置，皆會在游標點爆發一圈向外擴散的半透明緋紅能量光環。
- **烏鴉互動爆發（點擊烏鴉）**：
  - 烏鴉觸發 `crowAttack` 動態，劇烈振翅躍起。
  - 同時向四周噴射散落 **25 根由純 CSS 渲染的黑色擬真羽毛**（包含羽毛黑曜石反光與中央銀色羽軸 `feather::after`）。
  - 伴隨 Web Audio API 合成的烏鴉掠風音效與 Toast 提示。
- **召喚幸運與再次占卜（按鈕點擊）**：
  - 按鈕帶有彈性按壓回饋（Press Scale Feedback）。
  - 自動平滑滾動至卡片區域。
  - 卡片觸發 3D 翻牌動畫（`cardReveal`），自隨機幸運庫中揭曉全新幸運物。
  - 爆發 22 顆飄散星芒粒子，並響起清澈空靈的水晶鐘鳴。
- **祝福提示框 (Toast Notification)**：
  - 點擊幸運卡片或幸運物誌卡片時，畫面底部滑出帶有毛玻璃質感的半透明祝福視窗（例如：`✦ 烏鴉的祝福已銘刻於心 ✦`）。
- **音效開關**：導覽列右上角設有音效切換鍵，可即時開啟或靜音所有互動音效。

## 🚀 專案啟動與使用說明

本專案為原生純前端架構，**無需安裝 Node.js、npm 或任何編譯工具**：

1. **直接開啟**：
   - 雙擊開啟專案目錄中的 `index.html`，即可使用任意現代瀏覽器（Google Chrome、Microsoft Edge、Safari、Firefox）流暢預覽與操作。
2. **本機伺服器（推薦）**：
   - 使用 VS Code 的 **Live Server** 擴充功能，或在專案根目錄下使用指令：
     ```bash
     # 使用 Python 啟動本機伺服器
     python -m http.server 8080
     ```
   - 瀏覽器造訪 `http://localhost:8080` 即可享有最流暢的音效與動畫體驗。
